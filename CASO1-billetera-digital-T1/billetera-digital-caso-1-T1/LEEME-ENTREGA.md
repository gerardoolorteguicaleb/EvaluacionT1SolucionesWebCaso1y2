# Caso 1 · Billetera Digital: Recarga y Movimientos

Entrega exclusiva Java Servlet/JSP.

- java-wallet/: fuentes, pruebas, pom.xml e instrucciones completas.
- release/billetera-digital-java.war: aplicación regenerada para Tomcat 10.1 y Java 17.

Seleccionar Code → Download ZIP en GibHub. Para ejecutar sin compilar: copia el WAR a webapps/ de Tomcat, inicia Tomcat y abre http://localhost:8080/billetera-digital-java/. Necesita Java 17 y Tomcat 10.1; Maven solo si recompila con mvn clean test package dentro de java-wallet/.

Lee java-wallet/README.md para instrucciones Windows/Linux, estructura, pruebas.
